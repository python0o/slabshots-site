# Slab Shots

One-page site for Slab Shots (short-form videos and websites for small businesses). Dev preview on GitHub Pages; production domain slabshotsmedia.com later.

Contact: help@slabshotsmedia.com

Drop posters at `samples/sample-1.jpg`, `sample-2.jpg`, and `sample-3.jpg`, and clips at `samples/sample-1.mp4`, `sample-2.mp4`, and `sample-3.mp4` (1080×1920). Until those files exist, the reel shows a coming-soon placeholder. They are unofficial fan concepts, not client projects.

Web design demo: `demos/marketplace-concept/` (unofficial marketplace homepage concept, not a store).

Fonts in `fonts/` are [Instrument Serif](https://fonts.google.com/specimen/Instrument+Serif) and [Outfit](https://fonts.google.com/specimen/Outfit), both under the SIL Open Font License. See `fonts/OFL-instrument-serif.txt` and `fonts/OFL-outfit.txt`.
